# MewClient Launcher

Современный, быстрый и красивый лаунчер для Minecraft, созданный на Electron.

## ✨ Возможности

- 🚀 Поддержка всех релизных версий Minecraft от **1.8.9** до самых новых
- 🎨 Современный интерфейс в стиле **Millida Launcher**
- 💾 Настройка оперативной памяти, папки игры и пути к Java
- 📜 Встроенная консоль для отслеживания логов
- 🖼️ Кастомная иконка приложения

## 🚀 Запуск для разработки

1. Установи [Node.js](https://nodejs.org) (LTS-версию).
